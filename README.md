# Customer Marketing Analysis Using Python

## Project Overview

This project analyzes customer spending behavior and marketing campaign performance using Python-based exploratory data analysis and data visualization techniques. The analysis focuses on identifying customer purchasing trends, demographic insights, and opportunities to improve marketing strategy and customer engagement.

## Objectives

* Analyze customer demographics and spending behavior
* Compare web and in-store purchasing activity
* Identify patterns in customer engagement
* Generate business insights and strategic recommendations

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Key Insights

* Higher-income customers demonstrated stronger purchasing behavior and increased revenue potential.
* Store purchases exceeded web purchases on average, indicating strong engagement with physical retail channels.
* Customer demographic trends suggested opportunities for targeted marketing and customer segmentation strategies.

## Business Recommendations

* Expand personalized marketing campaigns for high-value customer segments.
* Continue strengthening in-store customer experiences while improving digital engagement strategies.
* Utilize customer segmentation techniques to improve marketing efficiency and customer retention.

## Files Included

* `customer_marketing_analysis.ipynb` — Full Python analysis notebook
* `marketing_campaign.csv` — Dataset used for analysis

## Conclusion

This project demonstrates how Python-based analytics and visualization techniques can support data-driven business decision-making and customer-focused marketing strategies.
